# 珠江新城院区高频检查检验患者指引：官方资料核验

核验日期：2026-08-05

## 结论

本轮公开检索没有找到广州市妇女儿童医疗中心发布、且能逐项确认珠江新城院区高频检查的报到地点、预约方式、准备时长和报告领取时限的官方页面。因此，指南可以写入跨机构一致、风险较低的通用动作，但所有院区特有信息和任何精确时长都必须在现场、预约单或院方渠道二次核验。

## 可写入指南的通用信息

### 所有项目共通

- 通用流程可写成“医生开单/缴费 → 到对应科室登记或扫码报到 → 候诊叫号 → 按工作人员指示检查 → 按院方告知查询报告”。官方医院公开流程显示，心电图、超声、影像和采血均可能要求先登记或扫码，但具体实现因机构和项目而异，不能据此推定珠江新城院区的窗口、楼层或系统。[济南市人民医院心电图流程](https://qsy.jinan.gov.cn/colqsy11503/art/2025/art_qsy11503_qsy70746.html)、[济宁市医疗机构公开的检查检验流程](https://dlrk.jining.gov.cn/art/2026/4/9/art_83947_2851093.html)
- 报告可能通过自助机或医院线上渠道查询，但领取时间会因项目、急诊与疑难病例而变化；珠江新城院区的入口名称和时限不能照搬其他医院。[济南市第五人民医院检验流程](https://qsy.jinan.gov.cn/col/col11151/art/2026/art_59bf9a9e3e754fd1890aae74730c0210.html)、[济南市中心医院影像流程](https://qsy.jinan.gov.cn/colqsy10157/art/2025/art_qsy10157_qsy69158.html)

### 抽血

- 不应把“抽血一律空腹”写成通则：公开医院指引明确区分空腹与非空腹项目，是否空腹及采样截止时间应按检验项目、医嘱和采血窗口要求确认。[济南市第五人民医院检验科指引](https://qsy.jinan.gov.cn/col/col11151/art/2026/art_59bf9a9e3e754fd1890aae74730c0210.html)
- 指南可提醒患者携带或准备就诊身份凭证，并在采血后确认报告时间和查询方式；具体凭证类型、条码生成方式及窗口号属于院区特有信息。[济南市第五人民医院检验科指引](https://qsy.jinan.gov.cn/col/col11151/art/2026/art_59bf9a9e3e754fd1890aae74730c0210.html)

### 尿液与粪便标本

- 尿标本应避免月经血、白带、粪便等污染，不应从尿布或便池取样；采集容器、尿段、采样时间与送达时限应按项目要求确认。[栖霞市中医医院临床检验指引](https://www.yantai.gov.cn/art/2025/4/16/art_86846_3249398.html)
- 粪便检查可提醒患者优先留取带有黏液、脓血等异常部分，但容器、样本量、禁忌药物及送检时限必须依检验单或检验科要求。[济宁市医疗机构公开的检验注意事项](https://dlrk.jining.gov.cn/art/2026/4/9/art_83947_2851093.html)

### 超声

- 超声准备取决于检查部位：肝胆胰脾等腹部项目常要求空腹；经腹盆腔或泌尿系统检查常要求膀胱充盈；经阴道超声通常要求排空膀胱；甲状腺、乳腺、心脏和外周血管等一般不要求空腹。[济南市第二人民医院超声须知](https://qsy.jinan.gov.cn/colqsy11019/art/2025/art_qsy11019_qsy51709.html)、[济南市第四人民医院超声注意事项](https://qsy.jinan.gov.cn/colqsy11107/art/2025/art_qsy11107_qsy62940.html)
- 儿童可能需要在安静或睡眠状态下完成检查，涉及镇静时只能由临床医生评估和安排，指南不得给出自行用药建议。[济南市第四人民医院超声注意事项](https://qsy.jinan.gov.cn/colqsy11107/art/2025/art_qsy11107_qsy62940.html)
- 产前筛查、胎儿心脏及部分心血管超声可能需要预约，但珠江新城院区哪些项目预约、如何预约必须由预约单或院方确认。[济南市第四人民医院超声注意事项](https://qsy.jinan.gov.cn/colqsy11107/art/2025/art_qsy11107_qsy62940.html)

### 常规心电图

- 可提示检查前短暂休息并保持平静；检查时按指示暴露前胸和四肢末端、平卧、避免说话和移动。幼儿可由一名家长协助安抚。[济南市人民医院心电图指引](https://qsy.jinan.gov.cn/colqsy11503/art/2025/art_qsy11503_qsy70746.html)
- 常规心电图通常不因进餐而取消，但动态心电图、运动试验等不是同一种项目，不能共用这张信息卡。[济南市人民医院心电图指引](https://qsy.jinan.gov.cn/colqsy11503/art/2025/art_qsy11503_qsy70746.html)

### X 线、CT 与 MRI

- X 线和 CT 可提示移除检查部位的金属或高密度物品，并在检查前主动告知怀孕或备孕情况；具体是否实施检查必须由临床和影像人员判断。[北京市卫生健康委员会转载北京清华长庚医院影像指引](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jksh/202304/t20230417_3057909.html)、[招远市中医医院影像信息](https://www.yantai.gov.cn/art/2025/1/10/art_68219_3029700.html)
- CT 的空腹、饮水、憋尿和呼吸配合要求取决于部位以及是否增强，不能写成统一时长；增强检查还涉及对比剂、过敏史、基础疾病、肾功能和用药评估，应只提示“提前完整告知并按医嘱准备”。[国家卫生健康委《X射线计算机体层摄影检查操作规程》WS/T 874—2025](https://www.nhc.gov.cn/fzs/c100048/202509/2f3f7cce449145f8b361e70b3ed4ae9a/files/WS%20T%20874%E2%80%942025-20250930105509517.pdf)
- MRI 不使用电离辐射，但强磁场带来独立的安全筛查要求；患者应提前申报植入物、金属异物及其他健康情况，腹部或增强 MRI 是否空腹须向医生确认。[国家医疗保障局 MRI 患者科普](https://www.nhsa.gov.cn/art/2024/7/14/art_14_13230.html)
- MRI 扫描室不能凭陪护需要自行进入；儿童、无法保持静止或有幽闭不适者需提前告知，镇静和陪同安排必须由院方决定。[济南市中心医院影像流程](https://qsy.jinan.gov.cn/colqsy10157/art/2025/art_qsy10157_qsy69158.html)

## 必须保持“以医嘱、预约单和检查科室为准”的信息

- 珠江新城院区的楼层、窗口、候诊区、扫码/取号方式、工作时间及联系电话。
- 是否需要预约、预约入口、提前到达时间及迟到处理。
- 禁食、禁水、饮水、憋尿、排尿、肠道准备的具体时长和剂量。
- 是否暂停或调整任何药物，尤其二甲双胍、胰岛素、抗凝药及镇静药；患者不得依据便利指南自行停药。
- CT/MRI 增强、镇静检查的适应证、禁忌证、肾功能要求、过敏风险评估、知情同意、陪护与检查后观察。
- 婴幼儿、孕妇、备孕者及行动不便者能否检查、是否优先、是否需要陪同或额外准备。
- 报告出具时限、纸质/电子报告入口、胶片获取方式及危急值沟通方式。

## 编辑建议

每张检查卡只写“通用准备提示 + 当天动作 + 明确的确认点”，避免写固定医学处置。例如：

> 是否空腹、饮水或憋尿取决于检查部位。先看预约单；仍不明确时，在进食、饮水或自行停药前联系检查科室确认。

院区特有字段只有在取得院方页面、预约通知截图（隐去个人信息）或现场核验记录后，才能标为“已核验”；否则应显示“待确认”，而不是用其他医院的流程补空。
