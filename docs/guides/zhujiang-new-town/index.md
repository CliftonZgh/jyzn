本页帮助第一次前往**广州市妇女儿童医疗中心珠江新城院区**的患者及陪诊者完成出发前确认和到院选择。当前公开资料不足以安全提供从入口到具体诊区的连续路线，因此本页不会猜测楼栋、楼层或步行路径。

!!! danger "急诊不使用本指南"
    本页不覆盖急诊、住院、分娩入院和院内转科。出现危急情况时，请立即联系当地急救服务或前往最近的急诊。

!!! warning "先核对预约单"
    预约单、医嘱、当天院内标识和工作人员指示优先于本页。出发前确认预约记录写的是“珠江新城院区”，不要只按医院简称导航。

## 选择怎么到院

<div class="grid cards" markdown>

-   :material-subway-variant:{ .lg .middle } **公共交通优先**

    ---

    APM 线设有“妇儿中心站”。现有一手资料尚不能确认从某个出口到门诊入口的当前连续路线，请使用实时公共交通或地图导航，到院后按现场标识前往。

    **适合：** 无必须驾车需求、希望避开停车排队。

-   :material-car:{ .lg .middle } **驾车**

    ---

    公开资料显示院内备案停车位有限，不能保证到场有位。出发前在“广州泊车”微信小程序查询或预约；驶近院区后以车位展示牌、入口标识和工作人员引导为准。

    **满位时：** 不在入口持续排队；由非驾驶者查询“广州泊车”中的周边实时车位并重新导航。

-   :material-car-side:{ .lg .middle } **即停即走下客**

    ---

    2024 年官方资料确认东门设有 7 个临停快走位。该位置只用于上下客，不是等候区；开放状态和驶入路径以当天现场指示为准。

    **注意：** 华夏路为全路段禁停区域，不在路边候客或长时间上下客。

</div>

## 到院后的安全动作

1. 核对院区名称和地址，确认已到“珠江新城院区”。
2. 打开预约单，找到正式科室或检查项目名称。
3. 查看大厅索引、报到提示或院内导诊屏，再决定前往方向。
4. 找不到位置时，向客户服务中心或现场工作人员出示预约单并询问。
5. 现场信息与本页不一致时，立即以现场指引为准。

## 检查当天怎么准备

是否空腹、饮水、憋尿、停药或提前到达，取决于具体检查项目。请先看医嘱和预约单；仍不明确时，在进食、饮水或自行调整药物前联系开单医生或检查科室确认。

- 不要把“抽血一律空腹”当作通则。
- CT/MRI 增强、镇静检查及儿童检查须按院方评估和安排准备。
- 到达检查区域后先确认是否需要登记、扫码或取号，并询问报告查询方式。
